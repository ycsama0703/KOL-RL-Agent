# Benchmark Compare Outputs

This folder stores merged comparison outputs generated by:

`benchmarks/01_generic_rl/build_compare_report.py`

Main files:

- `summary_by_kol.csv`: one row per `(source, KOL)`, with all methods side-by-side.
- `summary_by_method_mean.csv`: mean metrics per method.
- `compare_manifest.json`: run metadata (methods/paths/mode).

Per-KOL subfolders:

- `event_metrics_compare.csv`
- `betrayal_metrics_compare.csv`
- `daily_metrics_compare.csv`
- `equity_daily_compare.csv`
- `equity_daily_compare.png`
