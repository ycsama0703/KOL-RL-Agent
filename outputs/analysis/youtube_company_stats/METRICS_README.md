# YouTube Company-Stats Metrics Guide

This document explains the metrics generated by:

- `scripts/analyze_company_strategy_stats.py`

Output directory:

- `outputs/analysis/youtube_company_stats`

## Input Assumptions

The script reads per-KOL CSV files and expects:

- `company`
- `sentiment` (numeric, where `>0` positive, `<0` negative, `==0` neutral)
- `publishedAt` or `published_at` (timestamp)

Preprocessing:

- `date` is parsed to UTC datetime
- `company` is normalized (lowercase, punctuation cleanup, spacing cleanup) when `--normalize-company` is enabled
- `sentiment_cls` is derived from `sentiment`: `positive / negative / neutral`

---

## File-by-File Meaning

### 1) Mention Frequency

- `global_frequency_stats.csv`
- `per_kol_frequency_stats.csv`
- `global_frequency_counts.csv`

Definitions:

- `mentions` = number of rows for a company
- `companies_total` = number of unique companies
- `mentioned_once_companies` = count of companies with `mentions == 1`
- `mentioned_once_pct` = `mentioned_once_companies / companies_total`
- `mentioned_ge2_companies` = count of companies with `mentions >= 2`
- `mentioned_ge2_pct` = `mentioned_ge2_companies / companies_total`
- `mentions_mean/median/p25/p50/p75/p90/max` = distribution summary of company-level mention counts

---

### 2) Silence Duration (Gap Between Mentions)

- `global_silence_stats.csv`
- `per_kol_silence_stats.csv`

Only companies with at least 2 mentions are eligible.

Scopes:

- `all`: all mentions
- `positive_only`: only positive mentions (`sentiment > 0`)
- `negative_only`: only negative mentions (`sentiment < 0`)

Definitions:

- `gap_days` = day difference between consecutive mentions of the same company
- `gaps_count` = number of computed gaps
- `gap_median_days` = median of `gap_days`
- `gap_p90_days` = 90th percentile of `gap_days`
- `gap_max_days` = maximum of `gap_days`

---

### 3) Sentiment Reversal

- `global_reversal_summary.csv`
- `per_kol_reversal_summary.csv`
- `global_reversal_by_company.csv`

Directional mentions are non-neutral mentions only (`sentiment != 0`).

A company is considered to have a reversal if, after the first directional sign, a later directional sign differs.

Important parameter:

- `--min-directional-mentions-for-reversal` (default: `2`)

Definitions:

- `directional_mentions` = number of non-neutral mentions for a company
- `ever_reversal` = whether sign flips at least once vs first directional sign
- `time_to_first_reversal_days` = days from first directional mention to first opposite-sign mention
- `companies_with_min_directional_mentions` = denominator for reversal rate
- `companies_with_reversal` = number of companies with `ever_reversal == True`
- `reversal_rate` = `companies_with_reversal / companies_with_min_directional_mentions`
- `ttf_median_days / ttf_p90_days / ttf_max_days` = distribution of time-to-first-reversal among reversing companies

---

### 4) Signal Imbalance + Transition

- `global_imbalance_summary.csv`
- `per_kol_imbalance_summary.csv`
- `global_transition_matrix.csv`

Definitions:

- `posts_total` = total rows
- `positive_count / negative_count / neutral_count` = class counts
- `positive_ratio / negative_ratio / neutral_ratio` = class ratios over total rows

Transition logic (within each company, sorted by time):

- count transitions from previous `sentiment_cls` to next `sentiment_cls`
- matrix states: `positive`, `negative`, `neutral`

Transition outputs:

- `from`, `to`, `count`
- `row_prob` = conditional probability from a source state row

Summary transition fields:

- `pos_to_neg_count`
- `p_next_neg_given_pos` = `pos_to_neg_count / total transitions starting from positive`
- `neg_to_pos_count`
- `p_next_pos_given_neg` = `neg_to_pos_count / total transitions starting from negative`

---

### 5) Long Silence After First Mention

- `global_followup_summary.csv`
- `per_kol_followup_summary.csv`
- `global_followup_by_company.csv`

Per-company base quantity:

- `days_to_first_followup` = days from first mention to second mention
- if a company is mentioned only once, `days_to_first_followup` is `NaN`

Window summaries (30/60/90 days):

- `no_followup_within_window_count`
- `no_followup_within_window_pct`

Where:

- a company is counted as "no follow-up within window" if:
  - it has no second mention (`NaN`), or
  - `days_to_first_followup > window_days`

## Notes and Caveats

1. Company-level analysis:
   - Metrics are computed on `company` entities (not ticker symbols).

2. Sentiment class threshold:
   - The script uses sign only:
     - `>0` positive
     - `<0` negative
     - `==0` neutral

3. Reversal denominator:
   - Controlled by `--min-directional-mentions-for-reversal`.

4. Time granularity:
   - Gaps and reversal timings are based on parsed UTC timestamps.
